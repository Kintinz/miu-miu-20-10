# Miu Miu 20/10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dependency-free, mobile-first Vietnamese 20/10 surprise landing page in `D:\prj-my\miu-miu-20-10`.

**Architecture:** A static `index.html` owns semantic sections and the inline Miu Miu illustration. `styles.css` owns tokens, responsive layout, and CSS-only animation states. `app.js` owns DOM event wiring and imports pure interaction state helpers from `src/interaction-state.js`; `src/interaction-state.mjs` re-exports the same helpers for the Node test entry point. The helpers are covered by Node's built-in test runner without adding dependencies.

**Tech Stack:** HTML5, CSS3, vanilla JavaScript ES modules, Node.js built-in `node:test` for pure state tests, Git.

**Spec:** `docs/superpowers/specs/2026-10-19-miu-miu-20-10-design.md`

## Global Constraints

- Local-only implementation in `D:\prj-my\miu-miu-20-10`; do not publish or deploy.
- Dependency-free runtime; do not add an external animation, UI, or font library.
- Primary device is mobile; preserve responsive desktop layout.
- Use the approved Miu Miu palette and character: cream cat with orange patches and red bow.
- Keep copy in Vietnamese and mark sample memories/images as replaceable content.
- No login, API, database, audio autoplay, analytics, or unrelated features.
- Respect `prefers-reduced-motion` and keep keyboard focus visible.

## Review Focus

- Repeated clicks on a gift or heart must not increment progress more than once; test in `tests/interaction-state.test.mjs`.
- The final gift must remain locked until all five hearts are collected; test in `tests/interaction-state.test.mjs`.
- Reduced-motion users must still receive identical content and interactions; inspect the CSS media query and run the manual checklist.
- Narrow mobile widths must not clip the main CTA or final message; verify with local browser viewport checks.
- Placeholder media must be visibly replaceable and must not imply that invented memories are real; inspect content markup before handoff.
